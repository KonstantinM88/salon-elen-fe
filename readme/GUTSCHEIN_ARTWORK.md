# Gutschein botanical artwork

Generated with the built-in image generation tool on 2026-11-10, one call per design; no CLI/API fallback. Botanical images are decorative artwork, not photographs of salon treatments or evidence of results. Live UI text is separate from the artwork. Generated originals remain untouched in the image-generation output directory.

All four final assets are saved in the repository. Sharp creates the 1000 × 1000 WebP derivatives; Next Image provides responsive display sizes. `public/images/gutschein/og.webp` is a deterministic 1200 × 630 crop of Orchid for social metadata.

Final prompt set:
